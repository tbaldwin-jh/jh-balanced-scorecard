Executive Dashboarding

Community bank Balanced Scorecard executive dashboards — monitor objectives against plan for board and L1 leadership. Markdown source: README.md · GitHub: tbaldwin-jh/jh-balanced-scorecard.

Problem & value

ProblemExecutives lack a single, objective-driven view that shows whether the institution is on track — without operational overload.
ValueFaster strategic decisions, asset-based planning, and a reusable BSC framework tied to Capstone KPIs and L1 proving metrics.
