Executive Dashboarding

Community bank Balanced Scorecard executive dashboards — monitor objectives against goals for board and L1 leadership. Markdown source: README.md.

Problem & value

ProblemExecutives lack a single, objective-driven view that shows whether the bank is on track — without operational overload.
ValueFaster strategic decisions, asset-based planning, and a reusable BSC framework tied to Capstone KPIs.
