### How grain, refresh, and targets work

- **Market / line grain** on deposit growth, household growth, retention, and commercial pipeline is a client-mapped L2 (region or FOM, plus Retail / Commercial / other lines the FI actually runs). It is not a fixed geography list.
- **Deposit growth** stays the L1-2 outcome. Drill 1 / 3 show the forward book: new operating-account opportunities, expected new core, and attrition / runoff risk.
- **Refresh family:** Call Report / GL ratios are quarterly; core / franchise / production tiles are monthly; CSI and engagement follow the last survey cycle. All current values are sample until certified.
- **Target change:** Definitions is read-only. Add and Edit stay on the bar; writes follow **Role permissions**. Each tile shows who approved the target and the effective date.

### Role permissions

Add and Edit stay visible. Controls the role cannot use are greyed out. The top-bar **Role** dropdown gates who can publish. Default is **Monitor**. Actual, peer, formula, CAMELS, cadence, and last refresh are never writable. Session only — refresh restores the sample. Live Gold writes must enforce the same rules server-side.

| Role | Can publish |
|------|-------------|
| Monitor | Nothing. Add and Edit stay visible but greyed out. |
| Planner | Wording and owner |
| ALCO | Wording, owner, and targets on ALCO-approved tiles (earnings / franchise) |
| Board | Wording, owner, and targets on Board-approved tiles (risk / capital) |
| Catalog | Add a proving tile, plus all wording and targets |
